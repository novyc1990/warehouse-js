# Склад — приложение на JavaScript

Учебный проект, выполненный в рамках обучения frontend-разработке в Skillbox. Приложение позволяет вести список вещей с указанием полки, веса и даты размещения.

## Возможности

- Добавление записей через форму с обязательными полями.
- Просмотр записей в таблице.
- Сортировка по названию, полке, весу и дате размещения (по возрастанию).
- Удаление записей, в том числе после сортировки.
- Сохранение данных между посещениями в localStorage браузера.
- Переключение между таблицей и формой без перезагрузки страницы.
- Динамическая загрузка модулей экранов и индикатор загрузки.

## Технологии

HTML, CSS, JavaScript, DOM API, ES-модули, динамический import(), localStorage. Без фреймворков и инструментов сборки.

## Запуск

Откройте папку проекта в VS Code и запустите index.html через расширение Live Server.

Альтернатива при установленном Python: выполните в папке проекта:

```sh
python -m http.server 8000
```

Затем откройте http://localhost:8000. Нужен запуск через HTTP-сервер: открытие index.html напрямую через file:// может блокировать загрузку модулей.

## Структура

- `index.html` — точка входа.
- `css/` — стили и нормализация.
- `js/index.js` — переключение экранов и динамические импорты.
- `js/components.js` — функции создания элементов интерфейса.
- `js/homeCard.js` — таблица, сортировка и удаление записей.
- `js/addCard.js` — форма добавления.
- `js/storage.js` — чтение и запись данных в localStorage.

## Особенности учебной версии

Данные хранятся только в текущем браузере; серверной базы данных и синхронизации нет. Первоначально таблица пустая — нажмите «Добавить запись». Редактирование записей и переключение направления сортировки не реализованы.

## Публикация

Проект можно разместить на статическом хостинге. Для GitHub Pages выберите в Settings → Pages источник Deploy from a branch, ветку main и папку / (root).
